# Changelog

## 1.0.0 (2026-11-12)

First release.

- `orhof.search`: tree search as composable higher-order functions (strategies, `search`,
  `explore`, `hylo`, `hylo-eager`, `converge`, `by-identity`) and, under `orhof.search.*`,
  the algorithms built on it.
- Optimization, decision making and validation namespaces as of the book's companion code.
